# 🍽️ Recipe Recommender ML  

Un système de recommandation de recettes basé sur le Machine Learning. Ce projet permet de suggérer des recettes à partir d'une recette existante ou d'une liste d'ingrédients en utilisant plusieurs modèles d'apprentissage automatique.  

## 📌 Fonctionnalités  

✅ Recommandation de recettes basée sur une recette d'entrée  
✅ Recommandation de recettes basée sur une liste d'ingrédients  
✅ Comparaison de plusieurs modèles (Word2Vec, TF-IDF, SVD, KNN)  

## 🛠️ Modèles Utilisés  

- **Word2Vec** : Modélisation des mots pour capturer leur contexte dans les recettes  
- **TF-IDF** : Représentation basée sur la fréquence et importance des mots  
- **SVD (Singular Value Decomposition)** : Réduction de dimension pour capturer les similarités  
- **KNN (K-Nearest Neighbors)** : Recherche des recettes les plus proches
